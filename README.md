# The Seven Apocalypses

This is **The Seven Apocalypses**. A game focused on constant pressure under the weight of personal relationship problems and community development. 
Deal with the seven apocalypses, defeat bosses, expand your village, find a girlfriend, and earn rewards!

This repository holds the official open-source code of the TSA server-side, as the game strictly adheres to the separation of client and server.

Focused on modularity, expandability, and modifiability, the code seeks to follow the principles of Object-Oriented Programming and the SOLID standards.
